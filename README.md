# IIT Week 1

Each program prints `Hello!` and then reverses the word `infrastructure`.

## Run the programs on Windows

```powershell
python hello.py
node hello.js
gcc hello.c -o hello.exe
.\hello.exe
```

## Expected output from each program

```text
Hello!
erutcurtsarfni
```

## Setup reflection

Python and JavaScript took the least setup to run because the Python interpreter and Node.js could each run a source file with one command. C took the most setup because it needed a compiler and a separate build step before the executable could run.
